API Access for Developers

For Programmatic Access: Use API Keys to integrate your applications with SIMORGH Platform.

How it works:

  1. Sign in to the Dashboard with your email and password
  2. Navigate to Credentials section in the sidebar
  3. Create a new API Key with appropriate scopes (ai:chat, ai:embedding, knowledge:read, etc.)
  4. Copy and securely store your API key (shown only once)
  5. Use the key in your applications:
Authorization: Bearer YOUR_API_KEY

Python SDK Example:

from simorgh_sdk import SimorghClient

client = SimorghClient(api_key="sk_test_...")

# AI Chat
response = client.ai.chat(
    model="reasoning",
    messages=[{"role": "user", "content": "Hello"}]
)

# Knowledge Search
results = client.knowledge.search(
    space_id="ks_...",
    query="research question"
)

Note: API Keys are for machine-to-machine authentication. For human users, always use the dashboard login.
